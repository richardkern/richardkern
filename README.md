# Richard Kern
 
Product Manager by trade, with about 20 years in New Zealand telecommunications across Telecom/Spark, Chorus, and now Voyager Internet, where I work on connectivity and wholesale products.
 
I picked up coding through The Odin Project and freeCodeCamp a few years back. Not a career change, more a deliberate effort to build enough skill to create things I'd otherwise have to commission. The projects here reflect that: narrow and practical, grounded in problems I actually understand.
 
---
 
### What I'm building
 
Right now: a personal site at [richardkern.nz](https://richardkern.nz) and a website rebuild for Westgate Baptist Church in Auckland, where I volunteer as tech lead. Both run on Next.js with Payload CMS v3, PostgreSQL, and Tailwind 4, deployed to a self-hosted VPS via Coolify.
 
---
 
### Outside of work
 
Aviation, kit cars and experimental aircraft construction, and an ongoing interest in building narrow B2B tools for domains I know well.
